# corpus-search

To start you need a __search.ini__ file.

It needs two sections
[label] and [filter]

Under [label] you have key a to z if needed. The value will be included in the GUI


[label]
a=My first corpus
b=My second corpus


The Filter contains the identifier for the coupus
[filter]
a=first
b=second

Where the corpus found in the __source__ subfolder is named first-corpus.xml and second-corpus.xml
